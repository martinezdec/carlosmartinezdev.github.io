# Carlos Martínez de Celis — Portfolio

Portfolio profesional como Level Designer / Game Designer.
Sitio estático de una sola página, sin dependencias ni build step.

🔗 **Live:** https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/

## Estructura

```
.
└── index.html   ← todo el sitio (HTML + CSS + JS en un único archivo)
```

## Cómo actualizarlo

1. Sustituye `index.html` por la nueva versión.
2. Haz commit y push a `main`.
3. GitHub Pages redeploya solo en 1–2 minutos. No hay que tocar nada más.

## Publicado con GitHub Pages

Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `root`.

## Dominio propio (opcional)

Settings → Pages → Custom domain → añade tu dominio y crea el registro DNS
(`CNAME` apuntando a `TU-USUARIO.github.io`, o registros `A` a las IPs de
GitHub Pages si usas el dominio raíz).
